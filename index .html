什么是有序 Logit 回归？

有序 Logit 回归（Ordered Logit Regression），又称比例优势模型（Proportional Odds Model），是用于分析有序分类因变量的统计方法。

典型应用场景

  • 李克特量表：非常不同意 → 不同意 → 中立 → 同意 → 非常同意
  • 评级系统：差 / 一般 / 好 / 优秀
  • 教育程度：小学 / 中学 / 大学 / 研究生
  • 满意度调查：非常不满意 → 非常满意
  • 疾病严重程度：轻度 / 中度 / 重度

为什么需要有序 Logit？

❌ 错误做法

  • OLS 回归：将有序类别当作连续数值处理，违反等距假设
  • 多项 Logit：忽略类别间的顺序信息，损失统计功效

✅ 有序 Logit 的优势

  • 尊重顺序：利用因变量的排序信息
  • 无需等距：不假设类别间距离相等
  • 更高效：比多项 Logit 估计更精确
  • 易解释：优势比提供直观解释
核心思想：估计自变量对"处于某一类别或更高类别"的对数几率的影响。

与多项 Logit 的区别

特征 有序 Logit 多项 Logit
因变量类型 有序分类 无序分类
利用顺序信息 ✅ 是 ❌ 否
参数数量 较少（更高效） 较多
关键假设 平行线假设 IIA 假设
解释方式 累积优势比 相对风险比

选择建议：如果因变量类别有明确顺序，优先使用有序 Logit。

05 / 15

平行线假设（Proportional Odds）

这是有序 Logit 模型的核心假设，也称为等斜率假设。

假设内容

自变量 X 对每个累积发生比的对数影响是相同的，即回归系数β在不同分割点上保持一致。

图形理解

想象多条平行的 S 型曲线，每条曲线代表一个分割点，但斜率（β）相同，仅截距（α）不同。

检验方法：Brant 检验、Score 检验。若假设不成立，可考虑广义有序 Logit 模型。
06 / 15

数学模型

设 Y 有 K 个有序类别：1, 2, ..., K

累积概率

P(Y ≤ j | X) = P(Y ≤ j) = π₁ + π₂ + ... + πⱼ

Logit 模型

logit[P(Y ≤ j)] = ln[P(Y ≤ j) / (1 - P(Y ≤ j))] = αⱼ - βX

或等价地：
ln[P(Y ≤ j) / P(Y > j)] = αⱼ - βX

参数说明

  • αⱼ：第 j 个分割点的截距（阈值）
  • β：回归系数（在所有分割点上相同）
  • X：自变量向量
07 / 15

潜变量（Latent Variable）解释

有序 Logit 可以理解为某个连续潜变量 Y* 的离散化表现。

潜变量模型

Y* = βX + ε, 其中 ε ~ Logistic(0, π²/3)

观测规则

Y = 1 若 Y* ≤ τ₁
Y = 2 若 τ₁ < Y* ≤ τ₂
...
Y = K 若 Y* > τK-1

阈值与截距的关系

阈值 τⱼ = -αⱼ，阈值必须严格递增：τ₁ < τ₂ < ... < τK-1

参数估计：极大似然法

有序 Logit 使用极大似然估计（MLE）来估计参数。

对数似然函数

ln L = Σᵢ Σⱼ yᵢⱼ · ln[P(Yᵢ = j | Xᵢ)]

估计步骤

  1. 基于数据构建似然函数
  2. 使用 Newton-Raphson 或 BFGS 等数值优化算法
  3. 迭代直至收敛
  4. 计算标准误和检验统计量
注意：MLE 估计量具有一致性、渐近正态性和有效性。

优势比（Odds Ratio）解释

exp(β) 给出了优势比，是最直观的解释方式。

OR > 1

X 增加 → Y 取更高值的几率增加

示例：OR = 1.5
收入每增加 1 单位，满意度达到"高"而非"低"的几率增加 50%

OR < 1

X 增加 → Y 取更高值的几率减少

示例：OR = 0.7
年龄每增加 1 岁，健康状况达到"优秀"而非"较差"的几率降低 30%

计算示例

若 β = 0.405, 则 OR = exp(0.405) ≈ 1.5
解释：X 每增加 1 单位，Y 达到更高类别的几率是原来的 1.5 倍

Stata 实现

基本命令

// 有序 Logit 回归
ologit satisfaction income age education, or

// 边际效应
margins, dydx(*) atmeans

// 预测概率
predict prob1 prob2 prob3 prob4 prob5

// 平行线假设检验
omodel ologit satisfaction income age education
brant, detail

输出解读

  • Coef.：回归系数β
  • Odds Ratio：优势比 exp(β)
  • P>|z|：显著性水平
  • [/cut]：分割点/阈值估计

R 语言实现

使用 MASS 包

# 加载包
library(MASS)

# 拟合模型
model <- polr(satisfaction ~ income + age + education,
              data = mydata, Hess = TRUE)

# 查看结果
summary(model)
exp(coef(model))  # 优势比

# 置信区间
exp(confint(model))

# 预测
predict(model, type = "probs")

其他有用包

  • ordinal：扩展功能
  • effects：可视化边际效应
  • brant：平行线假设检验

模型诊断与检验

1. 平行线假设检验

Stata: brant, detail
R: brant(model)

若 p < 0.05，拒绝原假设 → 考虑广义有序 Logit

2. 模型拟合优度

  • Pseudo R²：McFadden、Nagelkerke
  • 似然比检验：与空模型比较
  • AIC/BIC：模型比较

3. 预测准确性

  • 计算正确分类率
  • 绘制 ROC 曲线（二分类合并时）
重要：始终检查残差和异常值！

实际案例分析

研究问题

什么因素影响员工的晋升意愿？（因变量：非常不想 / 不想 / 无所谓 / 想 / 非常想）

自变量

  • 年龄（连续）
  • 工作年限（连续）
  • 教育程度（分类）
  • 薪资水平（连续）
  • 工作满意度（有序）

关键发现示例

  • 工作满意度 OR = 2.1 (p < 0.01)：满意度越高，晋升意愿越强
  • 年龄 OR = 0.95 (p < 0.05)：年龄越大，晋升意愿越低
  • Brant 检验 p = 0.12：平行线假设成立

总结与要点

核心要点

  • 有序 Logit 适用于有序分类因变量
  • 利用顺序信息，比多项 Logit 更高效
  • 核心假设是平行线假设
  • 优势比 exp(β) 提供直观解释
  • 需检验假设是否成立

何时使用

当你的因变量是有序分类变量，且平行线假设通过检验时，有序 Logit 是首选方法。
